📦 Закрытие месяца: детали периода → архив, базы регионов и долги клиентов сворачиваются, прибыль → псевдоклиент. НЕОБРАТИМО. Сначала превью — кнопка закрытия появится только при farq ДО = ПОСЛЕ.
💰 Распределение прибыли: из прибыли месяца вычитается расход того же месяца, половина остатка идёт в кассу, вторая половина делится между инвесторами по их балансам. Сперва «Посчитать» — кнопка распределения появится только когда всё сойдётся.
